# 🌐✨ Real-time Language Translator

> 🖥️ A powerful and interactive desktop application built with **Python**, **Tkinter**, and **Google APIs** for translating and vocalizing text across multiple languages.

---

## 🚀 Features

🔹 **Multilingual Support**  
Translate between more than **15+ popular languages**, including regional Indian languages.

🔹 **Text-to-Speech (TTS)**  
Let your computer speak the translated text using **gTTS (Google Text-to-Speech)** and **Pygame**.

🔹 **Audio Playback & Replay**  
Listen to the translated text anytime using built-in audio playback controls.

🔹 **Translation History**  
Automatically stores the latest **5 translations** in a local **SQLite database**.

🔹 **Downloadable Audio**  
Save the spoken version of your translations as `.mp3` files.

🔹 **Responsive Scrollable UI**  
A clean and user-friendly interface made with **Tkinter canvas + scrollbar**.

---

## 🧰 Tech Stack

| Component      | Description                               |
|----------------|-------------------------------------------|
| 🐍 Python       | Backend language                          |
| 🖼️ Tkinter      | GUI library for the desktop interface     |
| 🌐 googletrans | Translation API (Google Translate)        |
| 🔊 gTTS         | Text-to-Speech conversion                 |
| 🎵 pygame       | Audio playback                            |
| 🗃️ SQLite       | Storing translation history               |
| 📋 pyperclip    | Clipboard copy support (planned)          |
